# Phase 2 — Neural Network Training (PyTorch)

## Goal

Train a deep neural network `h_θ(s)` that approximates the optimal cost for any Rubik's Cube state `s`. This is a **supervised regression** task using the 100M `[State, Cost]` pairs generated by Phase 1.

The learned heuristic is intentionally **non-admissible** — it may overestimate, which is the property being studied in Phase 3.

## Input: Phase 1 Dataset

Binary files at `D:\Search_DB\dataset_NNN.bin`. Reading them:

```python
import numpy as np, struct

def read_dataset(path):
    with open(path, 'rb') as f:
        magic, version = struct.unpack('<II', f.read(8))
        n_records = struct.unpack('<Q', f.read(8))[0]
        raw = np.frombuffer(f.read(n_records * 21), dtype=np.uint8)
    records = raw.reshape(-1, 21)
    states = records[:, :20]   # (N, 20) — raw cubie array
    costs  = records[:, 20]    # (N,)    — optimal depth 0..20
    return states, costs
```

## State Encoding Options

The raw 20-byte cubie array needs to be converted to a neural network input.
Two main options:

| Encoding              | Size        | Notes                                          |
|-----------------------|-------------|------------------------------------------------|
| One-hot facelets      | 54 × 6 = 324 bits | Directly mirrors the visual cube; used by DeepCubeA |
| Raw cubie embedding   | 20 bytes → learned embedding | More compact; requires an embedding layer |

Decision to be made at the start of Phase 2.

## Model Architecture (TBD)

Likely a fully-connected residual network similar to DeepCubeA:
- Input: encoded cube state
- Hidden: several residual blocks
- Output: single scalar `h_θ(s)` (regression)
- Loss: MSE or Huber loss against the optimal cost label

## Key Considerations

- **Non-admissibility**: The model will occasionally overestimate. This is intentional — Phase 3 studies *how much* overestimation affects search quality.
- **Dataset balance**: The uniform random generation in Phase 1 produces mostly depth-17/18 states. Consider oversampling shallow states if the model struggles at low depths.
- **Normalisation**: Costs range 0–20. Normalise to [0, 1] or standardise before training.

## Output

A saved model checkpoint (`.pt` file) that can be loaded by Phase 3's search harness.
