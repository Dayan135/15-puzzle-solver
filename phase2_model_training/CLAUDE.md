# Phase 2 — Neural Network Training (PyTorch)

## Goal

Train a deep neural network `h_θ(s)` that approximates the optimal cost for any 15-puzzle state
`s`. This is a **supervised regression** task using the `[State, Cost]` pairs generated by Phase 1.

The learned heuristic is intentionally **non-admissible** — it may overestimate, which is the
property being studied in Phase 3.

## Input: Phase 1 Dataset

Binary files at `dataset_NNN.bin` (9 bytes/record). Reading them:

```python
import struct

def read_dataset(path):
    with open(path, 'rb') as f:
        magic, version = struct.unpack('<II', f.read(8))
        n = struct.unpack('<Q', f.read(8))[0]
        for _ in range(n):
            state, cost = struct.unpack('<QB', f.read(9))
            yield state, cost
```

## State Encoding Options

The raw `uint64_t` state (16 nibbles) needs to be converted to a network input.

| Encoding            | Size      | Notes                                                  |
|---------------------|-----------|--------------------------------------------------------|
| One-hot per cell    | 16 × 16 = 256 bits | One-hot over 16 possible tiles per cell      |
| Raw nibbles         | 16 × 4 bits | Compact; requires the model to learn tile semantics  |

Decision to be made at the start of Phase 2.

## Model Architecture (TBD)

Likely a fully-connected residual network:
- Input: encoded state
- Hidden: several residual blocks
- Output: single scalar `h_θ(s)` (regression)
- Loss: MSE or Huber loss against the optimal cost label

## Key Considerations

- **Non-admissibility**: The model will occasionally overestimate. Intentional — Phase 3 studies
  how much overestimation affects search quality.
- **Dataset balance**: move-based scrambling with 1000 steps produces states deep in the search
  space. Consider oversampling shallow states if the model struggles at low depths.
- **Normalisation**: Costs range 0–80 (theoretical max for 15-puzzle). Normalise before training.

## Output

A saved model checkpoint (`.pt`) loadable by Phase 3's search harness.
