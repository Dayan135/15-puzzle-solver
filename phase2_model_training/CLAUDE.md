# Phase 2 — Neural Network Training (PyTorch)

## Goal

Train two neural network heuristics `h_θ(s)` that approximate the optimal cost for any
15-puzzle state `s`, using the `[State, Cost]` pairs generated by Phase 1.

Two model variants are trained independently and compared across two runs:

| Variant | Run | Input | Output | Loss | Admissibility strategy |
|---------|-----|-------|--------|------|------------------------|
| `PuzzleClassifier` | 2 | 256-dim one-hot | P(cost = k), k ∈ {0..80} | CrossEntropyLoss | CDF quantile (tunable threshold) |
| `PuzzleRegressor` | 2 | 256-dim one-hot | scalar h*(s) | PinballLoss (τ=0.3) | overestimation penalized 2.3× |
| `PuzzleClassifierV2` | 3 | 272-dim (one-hot + MD) | P(residual = k), k ∈ {0..44} | CrossEntropyLoss | CDF quantile (tunable threshold) |
| `PuzzleRegressorV2` | 3 | 272-dim (one-hot + MD) | scalar residual r(s) | PinballLoss (τ=0.3) | overestimation penalized 2.3× |

Run 3 models predict the **residual** r(s) = h*(s) − MD_sum(s) instead of h*(s) directly.
Empirical residual range over 100M records: [0, 34]. Phase 3 reconstructs h_hat(s) = r_hat(s) + MD_sum(s).

The learned heuristics are intentionally **non-admissible by default** — studying how
much overestimation affects search effort vs. solution quality is the thesis question
answered in Phase 3.

## Classes

### `data/puzzle_dataset.py`

#### `PuzzleDataset`
Loads Phase 1 binary `.bin` files into memory as numpy arrays.

- `__init__(paths, normalize_cost=True)` — accepts a file, list of files, or directory
  (auto-globs `dataset_*.bin`). Loads all records into RAM (~0.9 GB for 100M records).
- `__getitem__(idx)` → `(x, y)` — encodes the uint64 state as a 256-dim one-hot float32
  tensor (16 cells × 16 tiles, exactly 16 ones); `y` is raw cost or `cost/80` depending
  on `normalize_cost`. **Training uses `normalize_cost=False`** (raw 0–80 integer costs).
- `__len__()` → number of records.

#### `CostBalancedSampler`
Draws samples so every cost value is equally likely, eliminating the statistical weight
of duplicates in shallow scramble buckets.

- `__init__(dataset, num_samples, seed)` — groups all dataset indices by cost value using
  a sorted flat array + `(start, size)` per cost; fully vectorized, zero per-item Python loop.
- `__iter__()` → yields `num_samples` indices: pick a cost uniformly, then a record of
  that cost uniformly. Mathematically identical to weighting each record by `1/count(cost)`.

#### `train_val_test_split`
- `train_val_test_split(dataset, fractions=(0.8, 0.1, 0.1), seed=42)` → `(train, val, test)`
  as `torch.utils.data.Subset` objects. **Splits on unique states, not records**, preventing
  data leakage:
  - **val/test**: exactly one record per unique state (first occurrence); fractions apply to
    the ~42M unique states, so val and test are each ~4.2M clean, non-overlapping records.
  - **train**: all records whose state falls in the train bucket, duplicates included;
    `CostBalancedSampler` then makes those duplicates statistically weightless.
  - `len(train) + len(val) + len(test)` < `len(dataset)` — duplicate records of val/test
    states are intentionally dropped (they are not needed for evaluation).

### `data/puzzle_dataset_v2.py`

#### `PuzzleDatasetV2`
272-dim input variant of `PuzzleDataset`, used for run-3 training.

- `__init__(paths, normalize_cost=False)` — same path resolution as `PuzzleDataset`.
  Decodes nibbles **and** pre-computes `md_sums` in 5M-record chunks to keep peak RAM
  at ~5 GB (naive full-array approach would allocate ~40 GB of int32 temporaries and OOM
  a 32 GB node). Total persistent memory: ~2.9 GB for 100M records.
- `__getitem__(idx)` → `(x: float32[272], y: float32, md_sum: float32)`
  - `x[0:256]` — one-hot per cell (identical to `PuzzleDataset`)
  - `x[256:272]` — per-cell Manhattan distance to goal tile position (includes blank cell)
  - `y` — raw h*(s) (not the residual; training loop computes `y − md_sum`)
  - `md_sum` — Σ MD for non-blank tiles; admissible lower bound; empirical range [0, 56],
    residual range [0, **34**] over 100M records
- `md_sums` attribute — `float32[N]`, accessible by `CostBalancedSampler` indirectly
  via `costs`. The sampler only needs `.costs`; md_sums flow through `__getitem__`.

`CostBalancedSampler` and `train_val_test_split` are re-exported from this module
and work identically with `PuzzleDatasetV2`.

### `model/classifier_v2.py`

#### `PuzzleClassifierV2`
45-class classifier predicting P(residual = k) for k ∈ {0..44}.

- `__init__(width=256, depth=4, input_dim=272)` — same ResBlock backbone;
  projection layer is `Linear(272, width)` instead of `Linear(256, width)`.
  **609,837 parameters** at defaults.
- `forward(x)` → residual logits `[B, 45]`.
- `predict(x)` → argmax residual as int tensor `[B]`.
- `predict_quantile(x, threshold=0.5, temperature=1.0)` → int tensor `[B]`.
  Temperature scaling is applied to logits before the CDF, allowing tail control
  without retraining. Phase 3 use: `h_hat = predict_quantile(x, t, T) + md_sum(state)`.

`NUM_RESIDUALS = 45` covers residuals 0–44; empirical max in dataset is **34**
(10 bins of headroom). Halved output space vs run-2 classifier → sharper CDF calibration.

---

### `model/regressor_v2.py`

#### `PuzzleRegressorV2`
Scalar residual regressor trained with PinballLoss.

- `__init__(width=256, depth=4, input_dim=272)` — same backbone; `Linear(272, width)` projection.
  **598,529 parameters** at defaults.
- `forward(x)` → raw residual prediction `[B, 1]`.
- `predict(x)` → `round(clamp(output, 0, 44))` as int tensor `[B]`.
  Phase 3 use: `h_hat = predict(x) + md_sum(state)`.

`MAX_RESIDUAL = 44` matches `NUM_RESIDUALS − 1` for a fair comparison range.

### `model/classifier.py`

#### `PuzzleClassifier`
Residual FC network predicting a probability distribution over 81 cost classes.

- `__init__(width=256, depth=4)` — builds: Linear(256→width)+ReLU → `depth` ResBlocks →
  Linear(width→81). **614,993 parameters** at defaults.
- `forward(x)` → logits `[B, 81]`. Use with `nn.CrossEntropyLoss`.
- `predict(x)` → int tensor `[B]`, argmax over logits (no_grad).
- `predict_quantile(x, threshold=0.5)` → int tensor `[B]` (no_grad). Returns the smallest
  cost class `k` such that `P(cost ≤ k) ≥ threshold`. Eliminates catastrophic tail
  overestimates (e.g. the 42-move outlier from run 1's argmax) and gives a tunable
  admissibility dial without retraining. Output is clamped to [0, 80] to handle float32
  CDF imprecision at threshold=1.0. Training is unchanged — CrossEntropyLoss stays.

  **Important:** `threshold` ≠ admissibility rate. CrossEntropyLoss produces uncalibrated
  probabilities. Find the correct threshold empirically by sweeping on the val set and
  picking the floor that achieves ≥ 99% admissibility.

#### `_ResBlock` (private)
Single residual block: `fc1→ReLU→fc2 + skip connection → LayerNorm`.

---

### `model/regressor.py`

#### `PuzzleRegressor`
Identical backbone to the classifier but with a single scalar output head, trained with
an asymmetric loss to bias predictions toward admissibility.

- `__init__(width=256, depth=4)` — builds: Linear(256→width)+ReLU → `depth` ResBlocks →
  Linear(width→1). **594,433 parameters** at defaults.
- `forward(x)` → raw scalar `[B, 1]`. Use with `PinballLoss`.
- `predict(x)` → int tensor `[B]`, applies `round(clamp(output, 0, 80))` (no_grad).

---

### `model/loss.py`

#### `PinballLoss`
Asymmetric loss that penalizes overestimation `(1 − τ)` times and underestimation `τ` times.

```
L(y, ŷ) = τ · max(y − ŷ, 0)  +  (1 − τ) · max(ŷ − y, 0)
```

- `__init__(tau=0.3)` — `τ < 0.5` → overestimates cost more. `τ=0.3` means the model
  learns the 30th percentile: ~70% of predictions will be ≤ true cost.
- `forward(pred, target)` → mean loss scalar. `pred` is squeezed to `[B]` internally.

### `train_v2.py` (run-3 script)

```
python train_v2.py --model {classifier,regressor} --config configs/{model}_v2.yaml [options]

Key options:
  --epochs            int    default 20
  --residual-target   flag   default True  — train on r(s)=h*(s)−MD_sum
  --no-residual-target        disable residual target (not recommended)
  --input-dim         int    default 272
  --out               str    default checkpoints_v2/
  --results           str    default results/run3/
```

Differences from `train.py`:
- Uses `PuzzleDatasetV2` — DataLoader yields `(x [272], y, md_sum)` triples.
- Loss target = `y − md_sum` (residual). For classifier: rounded and clamped to [0, 44].
- Admissibility metrics computed in h*(s) space: `h_hat = pred_residual + md_sum`,
  `err = h_hat − y`. The val MAE printed each epoch is in original move units, not residual units.
- Checkpoints saved to `checkpoints_v2/{classifier,regressor}/`; results to `results/run3/`.

**Training loop per epoch (identical structure to `train.py`):**
1. `CostBalancedSampler` draws `len(train_split)` cost-balanced indices
2. Forward → residual loss → AdamW step
3. CosineAnnealingLR step
4. Evaluate on val split (metrics in h* space) → log `val_mae`, `val_admissibility_rate`
5. Save `best_model.pt` if val MAE improved

**Metrics** (all in h* space, directly comparable to run-2 numbers):
- `val_mae` — mean |h_hat − h*| in moves
- `val_admissibility_rate` — fraction where h_hat ≤ h*

## Input: Phase 1 Dataset

Binary files at `dataset_NNN.bin` (9 bytes/record):
- Header 16 bytes: magic `0x50313544` + version + n_records
- Record 9 bytes: `uint64` state (nibble-packed board) + `uint8` cost

## State Encoding — one-hot per cell (256-dim) — DECIDED

Raw `uint64_t` state → **16 cells × 16-way one-hot = 256 floats** (exactly 16 ones).

| Option | Problem |
|--------|---------|
| Raw `uint64` as float | ~10¹⁹ magnitude saturates the net |
| 16 nibbles as ints 0–15 | Imposes false ordering ("tile 12 > tile 3") |
| **One-hot per cell (256)** ✅ | Tiles are categorical — no magnitude, no ordering |

## Dataset Balance

100M records are only **42.1% distinct** — shallow buckets repeat a few near-goal states
millions of times. Two mechanisms handle this:

1. **`train_val_test_split`** partitions on *unique states* so the same state never appears
   in both train and val/test. Val and test each hold one record per unique state, giving
   clean, leak-free evaluation.
2. **`CostBalancedSampler`** makes duplicates statistically weightless during training by
   drawing each cost value with equal probability, at zero memory cost (no on-disk dedup).

See `TEST_RESULTS.md`.
